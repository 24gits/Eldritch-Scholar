## ✨ Features

- **Gothic Dark Palette:** Immersive deep amethyst, obsidian black, and rich parchment ink tones (`#120e16`, `#0d0a10`, `#c792ea`).
    
- **Scholar Typography:** Custom typography integration featuring **IM FELL English** for headers/editors and **EB Garamond** for clean reading views.
    
- **Futuristic Neon Accents:** Subtle 1px gradient borders and glowing metallic highlights replacing standard harsh borders.
    
- **Zero Clutter:** Aggressive border and line removal for a seamless, distraction-free writing environment.
    
- **Custom Scrollbars & UI Elements:** Fully styled settings menus, modals, and file explorers matching the dark arcane aesthetic.
    

## 📥 Installation

### Method 1: Inside Obsidian (Recommended)

1. Open Obsidian and go to **Settings > Appearance > Themes**.
    
2. Click on **Manage**.
    
3. Search for **"Eldritch Scholar"**.
    
4. Click **Install and Use**.
    

### Method 2: Manual Installation

1. Download the latest release zip file from the [suspicious link removed].
    
2. Extract the folder into your vault's `.obsidian/themes/` directory.
    
3. Reload Obsidian and select **Eldritch Scholar** from your Appearance settings.
